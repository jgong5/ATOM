**The contradiction.** `shape.py`'s module docstring (lines 53-57) still says the
term for any collective other than the all-reduce says the depth stands in *"for a
count of expert-bearing layers"*.

It does not. Measured at PR #140's head: **the emitted provenance contains no
`expert` at all.** `DEPTH_STANDS_IN`'s own comment, a hundred lines below, says
the constant "names no collective and no kind of layer" — which is the correction
round 3 made after round 2 rejected the general claim.

So the file holds two contradictory statements about its own output, and **the
false one is the exact shape round 2 rejected.**

**Why it was not blocked.** No number, refusal or emitted record changes. The
prose is contradicted by a constant in the same file and by a test, so it is
self-revealing on contact — unlike rounds 1 and 2, which both found output that
looked right and was wrong.

**Why it still needs closing.** A module docstring is where a reader starts. One
that describes emitted text the code does not emit is the defect this file spent
three cycles removing from the emitted side; leaving it on the prose side is
half a fix.

**What a fix has to do, and what it must not.** Correct lines 53-57 to describe
what the term actually carries. **This is one line of prose.** Do not take the
opportunity to restate the argument, re-derive the counts, or add a test — there
is already a test asserting the emitted text, and it passes. A round that grows
this into a paragraph is the failure mode the effort discussion exists about.

**Exit criterion.** The module docstring and `DEPTH_STANDS_IN`'s comment say the
same thing, and a reader of the docstring is not told about a kind of layer the
package does not count.
